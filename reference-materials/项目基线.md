## 《大傩幻梦》项目基线

《大傩幻梦》的核心设定是：**一个身处现代困境的人来到“傩”前求愿，傩从其具体诉求背后识别出更深层的情绪与人类困境，并借一场跨越千年的幻梦回应来者，最后为其授予一张面、一项职司和一份含混但有所指引的傩解。** 项目并不宣称古代傩仪能够真实改变现代现实，而是借用傩文化处理未知、灾厄、愿望与秩序的仪式结构，使游客意识到，虽然古今社会、文明与技术条件不同，人面对恐惧、失去、犹疑、渴望和无力感时，仍然存在深层的情绪共通性。产品的文化价值由此不只是展示傩面，而是让游客通过一次个人化叙事，与千年前的人发生情绪上的照面。

整个体验采用“**入戏—幻梦—得面**”三阶段结构。三者不是三个并列功能，而是一条完整的因果链：入戏负责理解现代人，幻梦负责建立古今共鸣，得面负责把这段体验凝结为可以带走的角色、图像、文字与文化知识。任何生成内容都应当能够沿着这条链条回溯，即面具和职司来自幻梦，幻梦来自用户的深层困境，而深层困境来自用户最初的求愿。

### 第一阶段：入戏

现代人向“傩”提出自己的愿望，系统以具有仪式感的方式收集三类信息：**所求何人、所求何事、汝之状貌**。其中，“所求何人”确定愿望所涉及的关系对象，“所求何事”提供显性的现实诉求，“汝之状貌”则可以包括昵称、自我描述、当前状态以及可选的面部信息。系统需要从这些表层信息中继续识别愿望背后的情绪、困境、恐惧、缺失与希冀，而不能停留在对用户原话的简单复述。

“傩”在这一阶段扮演的不是算命先生，也不是心理咨询师，而是一个能够听见愿望深层回声的叙事主体。用户也许求的是一次考试、一个人的回应或一段旅途顺利，但傩所捕捉到的可能是对失败的恐惧、对失去关系的忧虑、对未来道路的不确定，或者希望自己被看见与承认。识别完成后，傩由此“想起”千年前曾经有人带着相似的情绪前来祈求，从而自然进入幻梦。

### 第二阶段：幻梦

“幻梦”是整个项目的情绪与文化核心。傩带领现代求愿者回到千年前，让其看见某位先祖在完全不同的社会背景和具体事件中，也曾经历过结构相似的困惑与彷徨。古今人物面对的现实问题不必相同，甚至不应被粗暴等同；真正形成连接的，是他们内心共同存在的恐惧、犹疑、执念、失落、守护欲或重新开始的愿望。

幻梦以类似文字冒险游戏过场剧情的形式呈现，预计由五至七幕构成。每一幕可以包含环境描写、先祖经历、傩的旁白、少量选择以及情绪推进，但它首先是一段短篇叙事，而不是复杂的分支游戏。故事素材应尽可能从真实存在的傩戏剧本、角色、仪式和地方故事中提炼，再根据现代用户的困境进行改编，使其既拥有文化母体，又能够真正回应当代情绪。

幻梦的作用不是替用户给出现实答案，而是完成一次跨时代的情绪映照。游客在故事中看到的不是“古人已经替我解决了相同问题”，而是“在如此不同的时代里，竟然也有人经历过这种感受，并曾经以自己的方式面对它”。故事结束时，先祖的选择、未竟之愿或获得的启示，将成为“傩”为现代游客授予职司和面具的理由。

### 第三阶段：得面

幻梦结束后，“傩”根据用户的求愿、深层情绪、先祖故事和剧情结果，生成一套完整的个人回应。核心产物不是单独的一张图片，而是由**傩面、职司、傩签、傩解与溯源**共同组成的“得面结果”。这些内容必须互相解释，形成一个具有明确来历和内在逻辑的新角色。

| 产物 | 当前定义                                                     |
| -- | -------------------------------------------------------- |
| 傩面 | 代表此次职司与幻梦结果的视觉形象；如采集用户面貌，可将其特征融入固定傩面语法，但该功能视开发量决定        |
| 职司 | 用户此次被授予的角色及其职责，例如归魂使、开路将军、扫余人；既可链接传统角色，也可根据现代困境创造不存在的新职司 |
| 傩签 | 八至十二个字的神秘短句，是角色对用户处境的高度凝练与自我解释                           |
| 傩解 | 类似答案之书或星盘解读的含混指引，不给出现实保证，但能与用户处境产生投射和解释空间                |
| 溯源 | 科普层内容，展示该角色借鉴的真实傩面、人物、纹样、职司、剧目、图片及其原始含义                  |

“得面”的关键原则是，新角色必须具有明确职司、视觉标志、出场理由和背景故事。职司不能只是好听的称号，傩面也不能只是根据头像随机生成的怪异脸孔；它们必须由幻梦中的矛盾与用户的现实困境共同推出。例如，只有当幻梦讲述了前路迷茫、涉及选择或勇往前行，用户才可能被授予开路类职司；只有当故事涉及迷失、寻找与重新认领自我时，归魂类职司才具有叙事上的必然性。

## 傩面生成的基本认识

项目采用“**有限角色、固定特征、允许变体**”作为傩面生成的基本逻辑。真实傩面通常拥有角色模板、职司和辨识性特征，但具体脸形、比例、表情、配色、纹饰及雕刻风格可以变化，因此AI不必只能从现有傩面中进行选择，也不能完全脱离角色语法随意创作。项目可以吸收真实傩面的历史特质与视觉规则，再结合现代人的面貌、个性和困境创造新的变体，甚至创造传统中不存在的新型职司。

我们存在以下可能方案： A 完全采用现有的傩面 B 根据现有为主，可以进行微调 C 使用多种傩面要素生产全新形象。视开发了决定

所谓“可溯源”并不要求每一个生成角色都伪装成历史上真实存在的傩神，而是要求系统能够说明传统与新创分别位于哪里。一个新角色可以借鉴某种真实傩面的双角、纵目、凤鸟、云纹或活动下颌，也可以继承开路、归魂、扫寨、勾愿等传统职能，但其现代名称、具体职责和针对的时代困境可以是新创造的。溯源模块负责公开这条创作链，使游客既能沉浸于幻梦，也能在体验结束后获得真实的傩文化知识。

## 核心范围与扩展边界

当前最小可行产品只依赖“入戏—幻梦—得面”成立。即使暂时无法完成高质量人脸融合，只要能够根据用户输入识别深层情绪、生成一段五至七幕的古今映照故事，并给出职司、傩签、傩解和真实文化溯源，项目的核心体验便已经完整。技术和展示上的增强不能反过来成为项目能否成立的前置条件。

可选扩展包括：采集玩家面部信息并融入固定傩面；增加更多传统剧本与职司母体；保存用户生成结果；建立公共的“百傩录”；让不同角色参与多人互动；将得面结果转化为实体打印、文创或景区任务。这些方向可以根据剩余开发时间逐步加入，但当前均不作为核心假设，也不应挤占幻梦叙事、角色逻辑和溯源质量的开发资源。

最后，可以将项目当前的核心表述凝练为：**《大傩幻梦》是一场面向现代人的数字求愿仪式。傩听见来者的愿，从中辨认出跨越时代的人类困境；它以一场千年幻梦让现代人与先祖相遇，继而授予来者一项职司、一张傩面和一份有所指向却不替人决定命运的傩解。用户最终得到的不是一个关于“你天生是谁”的答案，而是一张关于“面对眼前之事，你可以暂时成为什么”的面。**
