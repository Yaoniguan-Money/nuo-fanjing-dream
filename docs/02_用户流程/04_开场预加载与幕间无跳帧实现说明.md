# 开场预加载与幕间无跳帧实现说明

负责人：队友（性能与剧情播放器）。优先级：P0。

## 1. 用户流程

`封面 → 点击“开始入梦” → 幻梦加载中 → 播放开场影片 → 问名/问惑/匹配 → 入戏`

加载页位于“开始入梦”之后、开场影片之前。封面不自动消失；用户点击后才启动有声媒体与高成本资源请求。

## 2. 加载页视觉

- 全屏延续封面暗坛与雾金气质，中央使用现有透明 Logo。
- Logo 下方固定文字：`幻梦加载中`。
- 下方一条细金线进度条；填充由暗金过渡至朱砂金，末端可有低频光点。
- 显示真实整数百分比；进度只能前进，不能倒退或长期卡在 99%。
- 避免通用圆形 Spinner、白色底板、厚圆角网页组件。
- `prefers-reduced-motion` 下取消粒子与扫光，只保留进度条长度变化。

## 3. 真实预加载策略

不要用固定 `setInterval` 伪造进度。建立可维护的关键资源 manifest，并按成功解码/可播放状态计算权重：

| 资源组 | 权重 | 就绪条件 |
| --- | ---: | --- |
| 开场影片首段 | 30% | `loadeddata`，不依赖不稳定的 `canplaythrough` |
| 封面至问名的背景、Logo、输入框和按钮 | 14% | 图片 `decode()` 完成 |
| 八张已核验主面具正面 | 28% | 八张全部 `decode()` 完成 |
| 匹配、盖面、得面公共 UI | 12% | 图片/SVG 与字体就绪 |
| 首屏脚本与路由块 | 8% | 动态导入、路由预取完成 |
| 安全余量 | 8% | 以上任务收束后填满 |

移动端并发上限 2，桌面端 4。开场阶段只加载八张正面；匹配出结果后再加载命中面具的侧面/背面及对应故事第一幕，避免手机同时解码全部高分辨率资产。

不要在开场一次性加载八个完整故事。剧情运行时仅预取“下一幕”的背景、角色和音频。

建议接口：

```ts
type LoadPhase = "boot" | "selected-story" | "next-act" | "ready" | "degraded";

preloadCriticalAssets({ onProgress, signal }): Promise<void>;
preloadSelectedStory({ maskId, storyId, onProgress, signal }): Promise<void>;
preloadNextAct({ storyId, actIndex, signal }): Promise<void>;
```

## 4. 时长与退出条件

- 最短可见时长：桌面 1.8 秒，移动端 2.4 秒，确保 Logo 和进度变化可被感知。
- 实际退出条件：`关键资源 100% 就绪` 且 `最短可见时长已结束`；不能只等固定秒数。
- 预期热缓存：桌面 1.8–2.5 秒，移动端 2.4–3.5 秒；首次慢网可能 3–8 秒。
- 10 秒仍未完成：文字改为 `山雾较浓，仍在载入……`。
- 15 秒仍未完成：显示 `轻量进入`，跳过开场影片并使用静态背景；八面正面和命中故事第一幕仍必须就绪。
- HTTP 缓存配合版本化文件名即可；本次黑客松不新增 Service Worker。

## 5. 幕间渐黑与资源门闩

每个故事从当前幕进入下一幕时必须执行：

1. 用户完成本幕最后一次操作；锁住继续按钮，防止重复触发。
2. 旧画面在 260–360ms 内渐黑，文字与角色同步退场。
3. 黑场期间等待下一幕背景 `decode()`、首屏角色图和必要音效就绪。
4. 资源就绪后先原子切换背景、角色和文本状态；禁止逐项更新导致背景跳变。
5. 新画面在 380–520ms 内渐显；渐显开始后再显示下一幕首句文字。
6. 解除交互锁，并异步预取再下一幕。

资源超过 1.2 秒仍未就绪时，黑场中央显示很弱的 `幻梦续写中…`；资源到位立即淡出。`prefers-reduced-motion` 下保留 80–120ms 的纯黑切换，仍需等待资源就绪。

## 6. 接入位置

- 开场：`src/features/threshold/threshold-experience.tsx`，新增 `loading` 阶段，位于 `dissolving` 和 `video` 之间。
- 新模块建议：`src/features/preload/boot-loader.tsx`、`preload-manifest.ts`、`preload.css`。
- 幕间：放在通用剧情播放器的 act 切换函数中，不能写进某一个故事 JSON。
- `入戏` 按钮只有在命中面具侧/背面和对应故事第一幕均就绪后才可点击。

## 7. 验收

- 桌面滚轮/触控板、iPhone 与 Android 真机分别测试首次加载和热缓存加载。
- Slow 4G 下从封面到问名无白屏；从匹配到故事首幕无素材闪白。
- 连续完成任意故事：各幕均先渐黑，下一幕背景与角色稳定后再出现文字。
- 进度单调递增；网络失败可进入轻量模式；取消或卸载组件后请求可通过 `AbortController` 终止。
- 八个 `maskId` 都可走同一加载接口，后续接模型不改视觉组件。
