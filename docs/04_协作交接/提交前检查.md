## 合并方先检查

1. 运行 `npm run typecheck` 与 `npm test`。
2. 运行 `npm run validate`，确认所有 `assetId`、剧情 JSON 和清单一致。
3. 在浏览器走四条已完成故事，确认故事结尾进入对应面具的揭示和收录页。
4. 在 `/codex` 验证八张卡面、演示模式、详情页实物翻面与相关图录放大。
5. 确认任何后续视觉改动均以 `purpleeerrr` 提供的资产为准。
