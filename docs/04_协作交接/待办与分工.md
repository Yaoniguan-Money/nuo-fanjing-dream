## 禁止跨界修改

- `purpleeerrr`：交互、视觉、AIGC 素材、Figma、页面文案的设计验收与替换决定。需要代码接入时，提供明确资产路径、命名、状态与目标页面。
- 队友（AI rulematching）：只负责匹配规则与接口接入；返回的结果必须是已定义的八职司 ID，不能生成新的角色名称、剧情或视觉资产。
- 内容负责人：只通过 `content/dream-cards/`、资产清单和注册表新增剧情；不能为单张故事改写播放器。
- 合并方：先执行 [提交前检查.md](提交前检查.md)，再合并；对资产路径或文字错配先回到本目录的索引确认权威来源。

## UI 重设计的统一规则

- 返回：取消胶囊按钮，使用低对比金线角框与箭头；只在悬停、聚焦时提亮。
- 输入：中央横向签框收窄，确认键与签框相连；输入聚焦时显示朱砂反馈。
- 匹配：面具承担视觉中心，信息区上移并压缩；八面使用真实前后层级、雾中明暗与遮挡。
- 得面与结束：标题、职司、操作固定为三级；`入戏`、`收录此面`、`出戏 · 见面`为唯一实感主按钮，重新观看降为文字操作。
- 图鉴：顶部工具栏拆成收藏进度、演示开关、剧情选择、返回四个低权重控件；卡牌状态由亮边、雾化、锁定图标表达。
- 品牌：保留用户指定的右下大 Logo；只调整位置、对比度与响应式尺寸，避免遮挡主操作。
- 字体：标题统一宋体展示字，功能文字使用中等字重宋体，正文使用更细宋体。
- 背景：统一暗场、烟雾、局部暖光；移除放射状金光、厚重圆角和普通网页按钮观感。
