# 大傩幻梦｜项目资料导航

本目录是给设计、剧情、前端与合并方使用的唯一资料入口。运行代码、运行素材与研究源文件保持各自的技术目录；本导航以用户流程和技术边界将它们汇总，避免通过复制文件制造第二份事实来源。

## 目录约定

- `src/`、`content/`、`public/` 是运行时权威目录，禁止为“整理”而移动，避免打断导入和素材 URL。
- `reference-materials/` 只存研究与原始来源，不由产品运行时直接加载。
- `docs/` 只保留说明、索引、协作交接与制作规范；本文件内所有本地链接使用相对路径。
- `../../../设计资料/` 位于项目仓库外，存放设计源文件与生成资产。本仓库通过资料索引引用它，正式运行素材仍需复制/登记至 `public/dream-assets/`。
